ARCHITECTURE HIGHLIGHTS:
=======================

1. DESIGN SYSTEM (Atomized, CVA-based)
   - Colors: Primary (orange), Accent (red), Neutral (gray scale)
   - Spacing: 12 scales (xs-5xl, 4px-128px)
   - Typography: 7 font sizes + 6 weights
   - Layout: Container, Stack, Grid, Flex, Section (zero hardcoding)
   - Components: Button, Card, Input, Label (shadcn/ui)
   - Responsive: Mobile-first, 5 breakpoints (sm-2xl)

2. DATABASE SCHEMA (Production-ready)
   Tables:
   - profiles (user data, role-based access)
   - products (unified catalog: ebooks, physical, subscriptions)
   - orders & order_items (purchase tracking)
   - download_links (7-day expiry, 5-download limit)
   - reviews (admin-managed)
   - blog_posts, faqs (content management)
   - site_config (admin-editable settings)
   - feature_flags (enable/disable features)
   - cart_items (shopping cart)
   - page_views (analytics)

3. AUTHENTICATION (Secure, Multi-Provider)
   - Email/Password signup & signin
   - Google OAuth integration
   - Session management (cookies + middleware)
   - Role-based access control (customer | admin)
   - Protected routes via middleware
   - Row-level security policies on all tables

4. STATE MANAGEMENT (Server-First)
   - Next.js 14 Server Components (default)
   - Server Actions for mutations
   - Minimal client-side state (theme, notifications, responsive)
   - No Redux/Zustand/Context except where needed
   - Cookie-based session persistence
